Part IV — Assets and agents

Assets: what the model writes, what it downloads, what it can't make

An LLM writes text. Everything visual in a scene is either generated by that text (code, shaders, procedural geometry), downloaded (HDRIs, textures, models, map tiles), or made by another AI service. Knowing which is which explains why some agent scenes look photoreal and others look like toys. It also tells you where licences can bite.

What an LLM can produce on its own

Can produce well (as code)Can't reasonably produce
  • Scene setup, lights, cameras, controls, post-processing
  • Procedural geometry: boxes, extrusions, lathes, terrain from noise, L-system trees, instanced cities
  • Shaders: water, sky, windows, fog, noise materials, toon outlines
  • Textures drawn in code: Canvas 2D or DataTexture gradients, patterns, normal maps from height fields
  • SVG decals, simple glTF JSON for tiny meshes
  • Sound via Web Audio synthesis
  • Detailed organic meshes (characters, cars, furniture with real topology)
  • UV-unwrapped, hand-painted textures
  • Photo-scanned PBR materials
  • HDRI photographs of real skies
  • Rigs and motion-capture animation
  • Photoreal cities (those are scans or map data)

Licence traps agents walk into
  • Three.js example models are not MIT. DamagedHelmet is CC BY-NC. Soldier, Michelle and Xbot are reportedly Mixamo characters (secondary source Unverified). Verified (DamagedHelmet README)

What to expect Practice:

  • Good single props and hero objects on a turntable.
  • Backs of objects are hallucinated from one view; text, thin parts and hands go wrong.
  • Topology is dense triangles, so vendors sell remesh, quad and low-poly options as extras. Inference
  • Scale and orientation are arbitrary.
  • Not suitable for building whole streets. Use procedural geometry or kits for that, and AI meshes for a statue, a car or a kiosk.

Agent integration. mcp-for-blender exposes Tripo, Hunyuan3D and Rodin as a generate_3d tool, so an agent can request a mesh, import it and place it in one session. Verified (README)

AI textures, materials and skyboxes

  • Adobe Substance 3D Sampler: Firefly-powered text-to-texture (beta since Sampler 4.4). Adobe states outputs are commercially usable.
  • Polycam AI Texture Generator: up to 4 tileable textures per prompt; downloads need a paid plan (Basic $30/mo).
  • Meshy: text-to-texture and retexture of uploaded meshes.
  • Blockade Labs Skybox AI: 360° skyboxes by API. The plans page lists $20 / $48 / $112 tiers; API access from the $48 tier; HDRI export and "commercial licensing" only on the top tier, which conflicts with marketing copy. Verified (page) / Unverified (which tier is truly commercial)
  • Open models: MatFuse (CVPR 2024, MIT, ≥12 GB VRAM) produces tileable PBR map sets; Material Palette extracts materials from one photo.

In practice, CC0 scanned PBR maps from Poly Haven and ambientCG still beat AI textures for realism, and they are free. Inference

Formats and pipeline

  • glTF / GLB (ISO/IEC 12113:2022) is the web delivery format. FBX and OBJ get converted (Blender, FBX2glTF). Verified
  • Compression:
    • Draco (Apache-2.0, 7,515 stars) and meshoptimizer (MIT, 8,581 stars, ships gltfpack) for geometry;
    • KTX2 / Basis for GPU-compressed textures, which saves VRAM compared with PNG or JPG;
    • glTF-Transform (MIT, 1,988 stars): gltf-transform optimize in.glb out.glb --texture-compress webp.
    GLTFLoader needs setDRACOLoader, setKTX2Loader or setMeshoptDecoder to read compressed files. Verified
  • Conventions (Khronos guidelines): right-handed, +Y up, 1 unit = 1 m, sRGB for base colour and emissive, linear for everything else, OpenGL-style normal maps (Poly Haven's nor_gl). Verified This explains most "imported model is huge, dark or inside-out" bugs.

Recommended practice

An asset policy to give your agent
  1. Prefer procedural, then CC0 (Poly Haven, ambientCG, Kenney, Quaternius, KayKit), then CC BY with credits. Nothing else without asking me.
  2. For every downloaded file, append to assets-manifest.json: source URL, author, licence, date, file hash. Some third-party asset MCP tools already write such receipts. Verified
  3. Show a credits overlay for any CC BY asset, and "© OpenStreetMap contributors" or Google credits for map data.
  4. Never copy Three.js example models into the project.
  5. Use Poly Haven through its API with a descriptive User-Agent; do not scrape the website.
