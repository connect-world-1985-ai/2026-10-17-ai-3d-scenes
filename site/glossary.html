Reference

Glossary

Short, practical definitions of the terms used in this guide, with a link to the page where each matters most. Type to filter.

Rendering

ACES / AgX (tone mapping)
Curves that compress HDR light values into displayable colours. AgX desaturates bright colours more naturally. See page 03.
Aliasing / antialiasing (MSAA, FXAA, TAA)
Jagged edges and shimmer, and the techniques against them. MSAA is hardware multisampling; FXAA is a cheap blur-like filter; TAA blends frames.
ANGLE
The layer in Chromium that translates WebGL into Direct3D, Metal or Vulkan. Its shader translation is why first frames can take seconds.
Bloom
A glow around bright pixels, added in post-processing. Too much washes the image out. See page 08.
Camera frustum, near and far
The visible pyramid between the near and far planes. Objects outside it are not drawn; a bad near/far ratio causes z-fighting. See page 02.
Cascaded shadow maps
Several shadow maps at different distances, so near shadows stay sharp over a large scene.
Draw call
One request from the CPU to the GPU to draw something. Usually the first performance limit in the browser. See page 05.
Emissive
A material channel for surfaces that give off light (windows, lamps). It does not light other objects unless you add lights or bloom.
Environment map (IBL, PMREM)
An image of the surroundings used to light and reflect PBR materials. PMREM is Three.js's pre-filtered version for rough surfaces.
Exposure
An overall brightness multiplier applied before tone mapping.
Fog (linear, exponential)
Blends distant objects into a colour. It hides the far plane and the edge of the world; it should match the sky colour.
Fragment shader
A GPU program run once per pixel that computes its colour. See page 04.
Fresnel
Surfaces reflect more at grazing angles. It is why the sea is a mirror near the horizon. See page 07.
Global illumination (GI)
Light bouncing between surfaces. Real-time engines approximate it (Lumen in Unreal); path tracers compute it.
HDR / HDRI
High-dynamic-range light values or images. An HDRI is a panoramic photo used as sky and lighting.
LOD (level of detail)
Using simpler versions of objects when they are far away.
Path tracing
Rendering by simulating many light paths per pixel: physically accurate, slow (Blender Cycles).
PBR (physically based rendering)
Materials described by base colour, metalness and roughness that respond plausibly to any light. See page 03.
Post-processing
Effects applied to the finished image: bloom, colour grading, SSAO, depth of field.
Raymarching / sphere tracing
Drawing a scene by stepping along rays through a signed distance field; the ShaderToy technique. See page 04.
SDF (signed distance field)
A function giving the distance from any point to the nearest surface.
Shadow acne / peter-panning
Stripe artefacts or floating shadows caused by the shadow bias being set too low or too high.
SSAO
Screen-space ambient occlusion: darkens creases and contact points cheaply.
Vertex shader
A GPU program run once per vertex. It moves vertices, for example ocean waves.
Z-fighting
Flicker where two surfaces sit at almost the same depth.

Scenes and techniques

FFT ocean (Tessendorf)
An ocean built from a wave spectrum with a Fast Fourier Transform. Film-quality; usually needs compute shaders (WebGPU).
Gerstner wave
A wave that moves points in circles, giving sharp crests and flat troughs. Sum several of them for an ocean. See page 07.
Instancing (InstancedMesh, BatchedMesh)
Drawing many copies of a mesh (InstancedMesh) or many different meshes (BatchedMesh) in one draw call. See page 05.
Kit-bashing
Building scenes from a set of reusable modular pieces.
Octree collision
A spatial tree that makes "does the player capsule hit the world?" fast. See page 06.
PCG (procedural content generation)
Generating content by rules and noise. In Unreal, PCG is also the name of its graph framework.
Pointer lock
A browser API that hides the cursor for mouse-look. It needs a real user click, so agents cannot test it directly.
Seeded noise (Perlin, simplex, value)
Smooth pseudo-random functions. The same seed gives the same city every time.
Spline camera path (Catmull-Rom)
A smooth curve through control points that a camera follows for a fly-over. See page 09.

Web platform

CDN and import map
A CDN hosts library files; an import map tells the browser where import 'three' comes from. Pin exact versions.
COOP / COEP / cross-origin isolation
HTTP headers needed for SharedArrayBuffer (Wasm threads). Plain Three.js does not need them. See page 13.
ES module
JavaScript loaded with import. Local module files do not load from file://, which is why this site uses classic scripts.
glTF / GLB
The standard runtime 3D format (ISO/IEC 12113). GLB is the single-file binary form.
KTX2 / Basis Universal
GPU-compressed texture formats that use much less memory than PNG or JPEG.
MediaRecorder / WebCodecs
Browser APIs for recording video in real time, and for encoding frames yourself. See page 13.
SwiftShader / WARP
Software GPUs used when no real GPU is available (for example headless CI). They are slow, so their FPS numbers mean little.
TSL (Three Shading Language)
Three.js's node-based shader language for WebGPURenderer; it compiles to WGSL or GLSL.
WebGL2
The mature browser GPU API (OpenGL ES 3.0), about 97% global support.
WebGPU / WGSL
The newer browser GPU API, with compute shaders; WGSL is its shader language. About 88% support by caniuse's count. See page 13.

Assets, capture and generation

CC0
A public-domain dedication: use for anything, no credit required. The safest licence for demos. See page 10.
CC-BY / CC-BY-NC
Credit required / additionally non-commercial only. A common trap with Sketchfab downloads.
Gaussian splatting (3DGS)
A scene captured from photos as millions of coloured, blurred ellipsoids. Photoreal and fast to render, but hard to edit or light.
NeRF
Neural radiance field: a learned volumetric scene from photos. Largely replaced by splats for real-time use.
Photogrammetry
Reconstructing a textured mesh from many photos.
3D Tiles
An OGC standard for streaming huge 3D datasets (cities, terrain) by level of detail; used by Google Photorealistic 3D Tiles and Cesium.
Image-to-3D / text-to-3D
AI services (Meshy, Tripo, Rodin, Hunyuan3D, TRELLIS) that generate a mesh from an image or text. Good for props, weak for whole scenes.
World model
An AI model that generates explorable 3D or video worlds (for example World Labs Marble). See route 7.

Agents

Agent / harness
A model running in a loop with tools (files, shell, browser). The harness is the program around it (Claude Code, Codex, Cursor, Stirrup).
Brief
The written specification given to an agent. Good briefs contain numbers, references, banned outcomes and a definition of done.
Critic subagent
A second agent that judges screenshots without seeing the code (night-street's "blind critic").
Elo / Bradley–Terry
Ratings computed from pairwise votes; used by AA-3D and the arenas. Overlapping confidence intervals mean "tied".
MCP (Model Context Protocol)
A standard for connecting agents to tools: browsers, Blender, Unreal, Unity, Godot. See page 11.
Playwright
A browser automation library; agents use it, directly or through an MCP server, to screenshot and test pages.
Rules file / skill
Persistent instructions for an agent (AGENTS.md, CLAUDE.md, .cursor/rules, SKILL.md). See page 15.
Vibe coding
Building software mostly by prompting, with little reading of the code.
