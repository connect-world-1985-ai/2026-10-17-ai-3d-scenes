Which GPU renders the page (Windows)

  • Hybrid-graphics laptops often run Chrome or Edge on the integrated GPU. Fix: Settings → System → Display → Graphics → add the browser → Options → High performance, restart, then check chrome://gpu or the probe above. Practice
  • powerPreference is not reliable on Windows. A Chrome engineer wrote in 2019 that Chrome and ANGLE "don't currently have the ability to select a particular GPU", and Chrome 80 changed the WebGL default to low-power. Whether this is still true in 2026: Unverified
  • ANGLE. Chrome on Windows translates WebGL to Direct3D 11 through ANGLE by default. Shader compilation through ANGLE explains long first-frame times: more than 95% of night-street's 35–39 s first frame on an RTX 4060. Verified (author's measurement)

Sources conflictcaniuse lists Firefox WebGPU as "disabled by default" and macOS Safari as "partial", while Mozilla and WebKit say both shipped. I trust the vendors for shipping status. Either way, the 87.82% figure is caniuse's estimate, not a measurement of how many users can run your WebGPU scene.

What this means for you:

  • WebGL2 is the safe baseline, and every demo in this guide uses it.
  • Three.js's WebGPURenderer falls back to WebGL2 automatically, but the official manual still calls it experimental.
  • WebGPURenderer does not support ShaderMaterial, onBeforeCompile or EffectComposer, which is most LLM-written shader code. Choose WebGPU when you need compute (FFT ocean, big particle systems) and accept writing TSL.

  • COOP/COEP: plain Three.js does not need cross-origin isolation. Wasm threads, some physics builds and ffmpeg.wasm do. Check with crossOriginIsolated in the console (see the probe above). Practice
  • Pin CDN versions (this site uses three@0.186.1 from unpkg). A forum report says unpkg once had CORS problems for newer three versions; it works today, but for anything long-lived, vendor the files or host your own copy. Practice
  • Map tiles: Google Photorealistic 3D Tiles must not be cached or used offline, and need the logo plus per-tile credits. See page 10.
