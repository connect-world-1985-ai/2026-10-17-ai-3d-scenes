Reference

Sources and method

How this guide was researched, what the evidence tags mean, the key sources behind each page, where sources disagree, and what was not checked. All research and every number are dated 2026-10-17 unless a source date is given.

Method

  1. Research. Six research subagents each wrote a fact sheet from fresh web sources, with a URL and an evidence tag on every claim:
    • browser real-time rendering;
    • shaders and recipes;
    • engines and MCP servers;
    • geodata, capture and generative 3D;
    • assets and licences;
    • agent workflows.
  2. Verification by the main agent. Key claims were re-checked before writing:
    • stars and licences of 25 repositories through the GitHub API (gh api repos/…);
    • the AA-3D launch article, re-read in full;
    • the night-street README and PROMPTS.md;
    • Epic's City Sample 5.8 page;
    • the Google Map Tiles policies;
    • Three.js r186 release notes, and the CDN response headers for three@0.186.1.
    Where a page wording went beyond its source, it was corrected.
  3. Writing. The main agent wrote every page and every demo.
  4. Testing. A Playwright script (playwright-core driving installed Microsoft Edge, headless, with --enable-unsafe-swiftshader):
    • opened every page from file://;
    • collected console errors and page errors;
    • screenshotted each demo and read its HUD;
    • repeated the runs offline (network blocked) and at 390 px width;
    • checked every internal link and #anchor.
    Demo screenshots used a software renderer, so their FPS numbers are not representative.

The working files (tracker, research notes, QA script and screenshots) are in docs/memory/memory-20261017-ai-3d-scenes-research/ next to this site.

Evidence tags

TagMeaning
VerifiedRead in a primary source (official docs, the repository, the vendor or author page, or an API response) during this research. For a demo, "Verified" means its prompt and code are public, not that I reproduced it.
PracticeWidely repeated engineering practice, or a credible secondary source (forums, blogs, one project's config).
InferenceMy reasoning from the facts shown. Treat it as an opinion with reasons.
UnverifiedNot confirmed: a lead, a single social post, or a search summary.
ExperimentalThe vendor itself labels the feature experimental or beta.
Plausible / PromotionalUsed only for demo claims on page 12: partly public and credible / marketing with nothing reproducible.

Rules followed:

  • Every count, price and star number carries a date.
  • Star counts and licences come from the GitHub API, not scraped pages (scrapes showed "0 stars" for large repos).
  • No number was invented. Where none was found, the page says so.
  • Model names are quoted as the sources give them.

Conflicts between sources

  1. AA-3D top score: the article gives Claude Sonnet 5.5 1194; the evaluation page 1197 ± 33, same date. The top four are tied either way.
  2. WebGPU in Firefox and Safari: caniuse says "disabled by default" / "partial"; Mozilla and WebKit say shipped. Vendor statements used for shipping status.
  3. WebGPURenderer maturity: the three.js manual says "experimental", while official examples and well-known sites ship on it.
  4. SwiftShader removal: blink-dev gives Chrome 137 / 139 experiments; a search summary says "disabled by default in 141". The exact version is unconfirmed; the opt-in flag works.
  5. Frame timing: night-street says gl.finish returns early in Chromium (use readPixels); Claudepunk2077 reports timings measured with gl.finish.
  6. Usefulness of skill packs: their READMEs claim docs-audited content; the night-street author found them "actively wrong" for high-end visuals.
  7. CCapture.js: the classic API in tutorials vs the 2026 rewrite in the README.
  8. Sketchfab ownership and downloads: sold by Epic to KitBash (2026-08-10); earlier messaging said downloads would end, the new owner says they continue.
  9. Prices:
    • Houdini Indie: $299 vs $269.
    • Houdini Engine: $525 vs $499.
    • Unreal subscription bundle contents.
    • Polycam plan names.
    • Marble's commercial-rights tier (terms vs billing page).
    • Google 3D Tiles: the price above the free cap is from a third party.
  10. Sea of Thieves ocean: often said to be Gerstner; Rare's paper says FFT.
  11. mrdoob's city: sometimes dated 2012; the evidence says 2013.

Known gaps and limits

  • No demo from other people was re-run. I did not reproduce any of the examples on page 12.
  • Browsers: the site was tested only in Chromium (Edge 154) from file://. Firefox and Safari were not tested; import maps and WebGL2 should work there, but this is unconfirmed.
  • Performance: no measured FPS on real integrated, discrete or mobile GPUs for any scene, mine or anyone else's. The demos' HUD numbers in testing came from a software renderer.
  • Demo limitations:
    • The city demo's street-level view is somewhat hazy at night (bloom plus fog).
    • The ocean demo's buoy looks dark when backlit by a low sun.
    • The 3D demos need the unpkg CDN; offline they show a fallback message. The raymarch and wave demos are raw WebGL and work offline.
  • Prices not researched: subscription plans for coding agents; CodePen and JSFiddle limits; Netlify and Vercel header configuration.
  • Not confirmed:
    • the CVE-2026-10688 status after the mcp-for-blender 2.0 rename;
    • the Blender Lab MCP licence;
    • Unity CLI screenshot tools;
    • Godot MCP screenshot support;
    • whether puppeteer-capture needs chrome-headless-shell.
  • No controlled study of whether skills or rules files improve AI-written 3D code.
  • Primary sources not read: Karpathy's post (secondary only), X/Twitter threads (mirrors only), Google AI Studio app system prompts.
  • Moving targets: star counts, prices and leaderboards change daily; every figure here is a 2026-10-17 snapshot.
