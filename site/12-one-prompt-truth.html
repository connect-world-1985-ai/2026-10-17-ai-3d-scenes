Part IV — Assets and agents

The truth behind "one short prompt"

"An AI built this photoreal city from one prompt" is a common headline. Where the prompts and code are public, the real story is nearly always different: a long, structured brief, hours of agent time with screenshot loops, or a short first prompt followed by a long conversation. This page classifies 17 public examples and gives you a checklist for judging the next one you see.

Four things "one prompt" can mean

A. Short prompt, long chat
A one-line first message, then dozens of follow-ups from a human. Example: fly.pieter.com ("after many questions and comments from me").
B. Long brief, long agent run
Hundreds of words with hard floors and banned outcomes; the agent runs for hours with self-screenshots. Examples: night-street, LAAS, AA-3D.
C. One file from one prompt
A single HTML file from a chat box. Real, but usually toy-sized: a voxel model, a small arcade game.
D. Marketing clip
A video with no prompt and no code. You cannot check it.

Inference from the examples below.

How examples are classified

  • Verified: the prompt and the code are public, so you can try to reproduce it. I did not re-run any of them.
  • Plausible: partly public and credible, but something important is missing (code, the full prompt, or the iteration history).
  • Promotional: marketing or a social-media claim with nothing reproducible.

Model names (for example "Claude Fable 5" or "GPT-6 Astra") are quoted as the sources state them. Stars are from the GitHub API on 2026-10-17.

What the verified examples have in common
  • A long brief with numbers: walking speed 1.4 m/s, a frame budget, banned looks.
  • A screenshot loop, often with a separate critic.
  • Persistent notes across sessions (STATUS.md, NOTES.md).
  • Hours of agent time.
  • Honest limits. night-street's first frame takes 34.9–39.4 s on an RTX 4060, more than 95% of it shader compilation.

Checklist: judging a "one prompt" claim

  1. Is the exact prompt published as text? Is it short (under about 100 words) or a multi-page brief?
  2. Is the code public and runnable? A pinned three version, no private assets.
  3. Are all turns shown? A chat export, commit history or PROMPTS.md. "Two prompts" is not one.
  4. Are time and cost stated? For scale, AA-3D allows up to 3 h and 250 turns, at $0.20–$32 per scene.
  5. Can you run it on your machine? Or is it only a video, possibly sped up, recorded on a high-end GPU?
  6. Was it built on a template or on earlier scaffolding? AI Studio bundled apps, or code reused from a previous project (night-street reused comments from an earlier one).
  7. Does a blind benchmark show similar quality for the same model?

Inference: my synthesis from the evidence above.

What one short prompt really gets you With a current frontier model and an agent that can see its output, one short prompt typically produces a working, decent-looking small scene in minutes: an ocean with a sky, a procedural low-poly city, a voxel model. The "impressive" level (photoreal lighting, a walkable district, good performance) has, in every verified case, needed a long brief, many iterations and hours of agent time. Inference
