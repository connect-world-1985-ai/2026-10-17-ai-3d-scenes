Part I — The landscape

Eight ways an "AI-made 3D scene" gets made

Two clips can look the same and have nothing in common underneath. One is a few hundred lines of JavaScript written by an agent. Another is Google's photogrammetry mesh of Tokyo, a Gaussian-splat scan, or an AI video with no 3D in it at all. The useful first question is not "which model?" but where do the pixels come from?

Route 1 — Browser real-time code

How it works. The agent writes an HTML page with JavaScript that builds a scene (objects, materials, lights, a camera) and redraws it about 60 times per second on your GPU through WebGL2 or WebGPU. Nothing is pre-rendered: you can move the camera, pause, change parameters. Pages 02–06 explain the moving parts.

Tools (all dated 2026-10-17, from the GitHub and npm APIs) Verified:

  • Three.js: r186 (npm 0.186.1), MIT, ~116.5k stars, ~21.4M npm downloads per week. It is by far the most common choice for agent-written scenes, and the one the AA-3D benchmark requires.
  • React Three Fiber 9.8.2 (~33.0k stars) puts Three.js in React; its helper library drei (~10k stars) has ready-made sky, water, environment and controls.
  • Babylon.js 9.31 (Apache-2.0, ~26.2k stars) is a fuller engine with an inspector, physics and splat loading built in.
  • PlayCanvas 2.23 (MIT, ~17.1k stars) is an engine plus a hosted editor (plans from free to $50 per seat per month).
  • Smaller options: A-Frame (VR-oriented HTML tags), OGL, regl, Threlte (Svelte), Needle (Unity-to-web exporter).

Cost and hardware. Free. Any recent laptop runs simple scenes; heavy post-processing and big cities need a discrete GPU to stay smooth.

How well an agent drives it. Best of all routes. Everything is text, the model has seen vast amounts of Three.js code, and the result can be checked automatically: open the page in a headless browser, read console errors, take a screenshot and look at it (page 11). The common catch is API drift. Three.js changes often and models still write code for removed APIs. Practice

How to spot it in a demo. The author can orbit and pause freely; geometry stays consistent from every angle; often there is an FPS counter, sliders or a GUI panel; shadows move when the light moves; shapes are often simple boxes and spheres unless glTF models are loaded.

Route 2 — Pure shader art (raymarching and ShaderToy)

How it works. There are no meshes. One fragment shader runs once for every pixel and, for each pixel, marches a ray into a scene described by maths (a signed distance function, SDF). Mountains, seas and whole cities can come from a few hundred lines. Page 04 has a live example: a whole city in one shader.

Classics. Seascape by Alexander Alekseev (TDM) is a sea from a noise heightfield with 32 march steps. Despite the look it uses neither Gerstner nor FFT waves Verified. Inigo Quilez's Rainforest and Elevated are terrain landmarks. Licence trap: ShaderToy's default licence is CC BY-NC-SA 3.0 (non-commercial, share-alike) unless the author states otherwise Verified.

Agent drivability. Good when the agent reuses well-known building blocks (iq's SDF primitives, fbm noise, soft shadows). Weak at large structured scenes, because everything has to be expressed as one distance function. Cost scales with screen pixels, so full-screen 4K on a laptop can crawl. Inference

Spotting cues. Impossible smoothness (blobs that merge), infinite repetition, perfect soft shadows and ambient occlusion, often a full-screen canvas with no UI. Moving the camera far away shows the same pattern repeating.

Route 3 — Game engines driven by an agent

How it works. The engine provides the renderer, lighting, physics, foliage and asset store. The agent drives the editor, either by writing scripts run headlessly or live through an MCP server (a standard plug-in protocol that lets an AI client call tools inside another app).

  • Unreal Engine 5.8 (latest hotfix 5.8.3, 2026-09-22) ships an Experimental built-in Unreal MCP server at http://127.0.0.1:8000/mcp. Epic's MIT-licensed Claude Code plugin (550 stars) teaches the agent its toolsets. Epic's City Sample update (2026-08-27) rebuilt the Matrix Awakens city inside UE with its Procedural Content Generation framework, "with assistance from the LLM (in this case, we used Claude…)". Verified Licence: free under $1M revenue; then a 5% royalty on game revenue above $1M per product, or $1,850 per seat per year for non-game companies above $1M.
  • Unity 6.6: Personal is free under $200K; Pro costs $2,310 per seat per year. Unity's own in-editor MCP server is deprecated in favour of the Unity CLI (unity mcp). Community servers: CoplayDev/unity-mcp (MIT, ~15.0k stars, has a camera screenshot tool) and IvanMurzak/Unity-MCP (Apache-2.0, ~4.5k stars).
  • Godot 4.7 (MIT, ~118.5k stars): fully scriptable headless (godot --headless --script), with community MCP servers godot-mcp (~6.1k stars) and godot-ai (~3.0k stars). Note: C# Godot projects cannot be exported to the web.

Hardware. Epic recommends Windows 11, 32 GB RAM and a DX12 GPU with at least 8 GB VRAM. City Sample alone is reported at about 90 GB on disk Practice.

Agent drivability. Good and improving fast, but harder than the browser: editor state is large and hidden, screenshots must be requested explicitly, and builds are slow. The strongest engine demos are agents orchestrating existing systems (PCG graphs, Megascans, Megaplants) rather than modelling geometry. Inference

Spotting cues. Film-grade global illumination (Lumen), dense foliage and photoreal assets, the Unreal or Unity editor UI in the recording, a downloadable executable rather than a link, multi-gigabyte projects.

Route 4 — Offline rendering in Blender

How it works. The agent writes Python against Blender's bpy API to build geometry, materials and lights, then renders with EEVEE (real-time rasteriser, seconds per frame) or Cycles (path tracer, tens of seconds to minutes per frame). It can run with no UI: blender -b --python build.py Verified. Or the agent drives a live Blender through an MCP server:

  • mcp-for-blender (formerly blender-mcp; MIT, ~31.3k stars), with a look tool for viewport and render screenshots plus Poly Haven, Sketchfab and AI-mesh integrations. Its execute_blender_code tool runs arbitrary Python (tracked as CVE-2026-10688), so use a throwaway project.
  • Blender's own Blender Lab MCP server (v1.0.3, needs Blender 5.1+), deliberately small.

Output. Images or video, not an interactive scene, unless you export glTF to a browser (route 8). This is the free route to path-traced quality.

Spotting cues. Physically perfect soft light and caustics, but the camera only moves along a fixed path; frame rate locked at 24 or 30 fps; no interactivity; render noise or denoiser smudges in dark corners.

Route 5 — Real-world geodata

How it works. A renderer streams map data of the real world: Google Photorealistic 3D Tiles (a photogrammetry mesh of many cities), OpenStreetMap or Overture building footprints extruded to boxes, terrain and satellite imagery. Renderers: CesiumJS 1.146 (Apache-2.0, ~15.8k stars), 3DTilesRendererJS (Three.js / Babylon / R3F), deck.gl, MapLibre (BSD) or Mapbox GL (proprietary since v2).

Cost and terms Verified:

  • Google 3D Tiles: 1,000 root-tileset requests per month free; one root request covers a session of at least 3 hours. Above that about $6 per 1,000 (secondary source Practice).
  • You must show the Google Maps logo and the data credits. No caching or offline use. Promotional videos are limited to 30 seconds and must be marked "for promotional purposes only".
  • Cesium ion Community is free for non-commercial use; Commercial costs $149/month.
  • OSM and Overture buildings are under the ODbL: attribute "© OpenStreetMap contributors".

Agent drivability. Excellent. Wiring CesiumJS to Google tiles is ~20 lines. But the realism is Google's, not the agent's: a gorgeous "AI-made Manhattan fly-over" usually means the agent wrote a camera path over someone else's mesh. Inference

Spotting cues. The Google Maps logo and a credits line at the bottom; melted or drooping buildings, smeared trees, flat cars; tiles sharpening ("popping") as you approach; a smooth zoom from orbit to street level. OSM extrusions look like untextured pastel boxes.

Route 6 — Captured reality (photogrammetry, NeRF, Gaussian splats)

How it works. You photograph or film a real place. Software reconstructs it as one of:

  • a textured mesh (photogrammetry: RealityScan, free under $1M revenue; COLMAP; Meshroom);
  • a neural radiance field (NeRF);
  • most commonly in 2026, a cloud of millions of 3D Gaussians: 3D Gaussian Splatting, Kerbl et al., SIGGRAPH 2023.

Web viewers such as Spark (MIT, ~3.8k stars, Three.js) and SuperSplat (MIT, ~10.4k stars) display splats at real-time rates.

Licence trap. The INRIA reference implementation (~24.2k stars) is research and non-commercial only. Commercial work uses other trainers (Postshot Indie, Polycam, Scaniverse and others). Verified

Agent drivability. The agent can write a viewer, convert formats and build a tour path. It cannot go outside and take the photos. Lighting is baked in: a time-of-day slider does nothing.

Spotting cues. Uncannily photoreal but soft edges; translucent "floaters" and haze; blurry areas off the original camera path; reflections that look painted on; a loading bar for a 20–400 MB .spz or .sog file.

Route 7 — Generative 3D, world models and AI video

Three very different products share the "generative" label:

7a Text or image to mesh

Services such as Meshy, Tripo and Rodin return a GLB mesh with textures in seconds to minutes. All three have REST APIs. Open models: TRELLIS.2 (MIT, ~12.1k stars; needs a 24 GB NVIDIA GPU) and Hunyuan3D 2.1. Hunyuan3D's licence excludes the EU, UK and South Korea. Verified Good for single props and hero objects; not for whole streets. Raw topology is dense and triangulated. Details and prices are on page 10.

7b World models that output 3D

World Labs Marble turns text or images into an explorable world exported as Gaussian splats or a mesh. The API costs 1,500 credits ≈ $1.20 per world. Tencent's HY-World 2.0 does similar with open weights (same territory restrictions). Verified

7c World models that output pixels only

Genie 3 (Project Genie, Google AI Ultra subscribers), Odyssey, Decart and HY-World 1.5 generate video frames in real time as you press keys. There is no 3D asset to export. Google lists control latency, worlds darkening over time and drift as known issues. Verified

7d AI video

Veo 3.1 makes 4–8 s clips (extendable up to about 148 s); Runway Gen-4.5 makes 2–10 s, Kling 3.0 3–15 s. Verified A "walkthrough" made this way is a film, not a scene.

Spotting cues for 7c and 7d. Cuts every 4–15 seconds; windows and signs that change between shots; text that mutates; no interaction; cinematic motion blur and colour grade instead of a HUD; impossibly smooth camera moves. World models add input latency and scenes that change when you look back.

Route 8 — Hybrids

The most impressive real demos usually combine routes. Typical mixes:

  • Agent-written Three.js scene + Poly Haven HDRI + a few CC0 glTF models (routes 1 + asset library).
  • Three.js + Google 3D Tiles background + agent-written traffic and weather (routes 1 + 5).
  • Unreal PCG graph driven by an agent + Megascans assets (route 3 + store assets).
  • Blender-generated building kit exported as glTF, assembled in the browser (routes 4 + 1).
  • Marble world exported as splats, rendered in Spark with agent-written gameplay (routes 7b + 1).

Demo-spotting checklist

When you watch a clip that claims "AI made this", run through these questions in order:

  1. Can the viewer move freely? If the clip only follows a fixed path, it could be anything, including video. Ask for a live link.
  2. Is there a logo or credits line (Google Maps, © OpenStreetMap, Cesium)? Then the city is data, not generated.
  3. Do edges look soft, with haze near the camera? Probably Gaussian splats.
  4. Do details change between shots, or are there cuts every few seconds? AI video.
  5. Do buildings repeat with identical shapes and procedural lit windows? Agent-written procedural city (routes 1 or 2). See page 08.
  6. Is there film-grade global illumination with dense foliage and an editor UI? Engine route.
  7. Is there a public repo with the prompts? If yes, read it. Then go to page 12 for how to judge it.
What this means for youFor learning and for agent-friendly iteration, route 1 (browser real-time) is the best place to start. It is free and fully inspectable, and it is the route the live demos in this guide use. Routes 5 and 6 buy realism you cannot code; route 3 buys production quality at the cost of hardware and complexity. Inference
